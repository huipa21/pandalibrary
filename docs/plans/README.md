# Plans

| Plan | Scope |
|---|---|
| [implementation-plan.md](./implementation-plan.md) | v1 build: tasks, dependencies, numbered steps (parallel tasks and serial gates), file ownership |
| [open-questions.md](./open-questions.md) | Resolved: the answers that shaped the plan and ADR-0001/0003/0004 |

A plan lists **what** and **in what order**. The detailed instructions for one task live in
`../prompts/<task-id>-<slug>.md`, written just before the task starts (see
[ADR-0004](../decisions/0004-docs-structure-and-agent-workflow.md)). Status is in
[../progress](../progress/README.md).
