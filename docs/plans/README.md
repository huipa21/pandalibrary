A plan lists **what** and **in what order**. The detailed instructions for one task live in
`../prompts/<task-id>-<slug>.md`, written just before the task starts (see
[ADR-0004](../decisions/0004-docs-structure-and-agent-workflow.md)). Status is in
[../progress](../progress/README.md).
